# Bluesky Photo Search

Application web de recherche de photos publiques sur Bluesky à partir de mots-clés.

Exemple : `chat roux à poils longs`

Objectifs :
- recherche par texte, sans URL Bluesky ;
- affichage des publications publiques contenant des images ;
- galerie avec auteur, texte, date et lien vers le post ;
- téléchargement individuel des images ;
- téléchargement groupé ;
- pagination / chargement progressif ;
- interface responsive en français ;
- déploiement prévu sur Vercel.
